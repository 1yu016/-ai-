# 课堂大屏操作手册

## 启动

1. 在大屏浏览器打开园所课堂大屏地址。
2. 选择已绑定的大屏设备；没有可用设备时显示等待状态，不伪造在线。
3. 教师开始课堂后，大屏自动显示当前课堂状态；刷新后由服务端状态恢复。

## 课堂中

大屏显示当前步骤、资源和播放状态，并接收教师端或手机端的统一课堂命令。资源播放失败只影响当前资源，不应让整页崩溃。数字人动作失败回到 idle，口型失败不阻断音频。

作品评价只有在教师确认后才可展示或朗读。大屏不展示未授权头像、声音、作品、敏感互动摘要或负面排名。

## 恢复和结束

实时连接断开时显示离线；重连后以服务端完整状态覆盖本地过期状态。课堂结束后显示结束或总结状态，不能继续执行课堂操作。外部 AI 断开时保留本地课堂按钮和安全降级提示。
