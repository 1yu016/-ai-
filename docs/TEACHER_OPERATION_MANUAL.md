# 教师操作手册（成员 B 前端交付）

## 日常上课

1. 打开园所地址并登录教师账号。
2. 进入“我的班级”，选择负责班级；跨班级页面由服务端权限控制。
3. 在备课中心打开教案。经验建议只作为候选，逐项处理后再通过既有教案保存流程保存。
4. 进入课堂准备页，确认大屏、网络、教案和资源状态。麦克风、AI 助教和数字人显示为可降级项时，仍可使用基础课堂控制。
5. 启动课堂后，在驾驶舱查看当前步骤、下一步骤、资源播放状态、大屏状态和服务端版本。
6. 资源须由教师操作打开；切换步骤前确认当前媒体是否需要停止。
7. 考勤、点名、奖励和课间操作以服务端确认结果为准。发送中不代表已执行。
8. 语音录音只能由教师主动点击或按住说话；ASR 结果是候选，涉及幼儿或课堂操作时必须确认。
9. 记录问题、拍摄作品或上传作品前，确认授权状态。AI 绘画评价必须先编辑并确认，未确认内容不会投递到大屏或朗读。
10. 结束课堂后查看复盘时间线和 AI 总结草稿；编辑并确认后才成为正式教师总结。

## 状态反馈

- **发送中**：请求已发出，等待服务端回执，不能再次点击重试相同操作。
- **已确认/已执行**：收到服务端成功回执后才显示。
- **冲突**：提示 409 时先重新拉取课堂状态，再决定是否继续编辑或操作。
- **离线**：实时连接中断；恢复后页面会重新鉴权并用服务端完整状态覆盖旧投影。
- **无权限**：返回上一层或工作台，不通过刷新绕过权限。

## 安全使用

只展示有授权的儿童照片、声音和作品；未授权时使用默认卡通头像。不得把儿童诊断、能力排名、家庭情况或负面标签写入课堂内容。不要连续重复点击，也不要把 Token 复制到资源地址。
