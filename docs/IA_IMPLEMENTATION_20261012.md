# 信息架构改造实施记录（2026-10-12）

## 范围与现有基础

基于阶段一、二已有的 BaseWorkspaceLayout、角色布局、PageHeader、BackButton、面包屑、403/404 与旧路由兼容继续实施。既有组件继续复用，不按设计书候选目录重复创建另一套组件。课堂准备、正式课堂、大屏、手机遥控本来就使用独立页面容器，继续保持该边界。

## 本次落地

- `/teacher/home`：教师教学首页，展示负责班级、进行中课堂，以及备课、资源、课堂记录入口。使用现有班级与 active-run API，不伪造统计或课表。
- `/classroom/history`：班级课堂记录列表，查询和分页使用 URL 保存；详情携带来源地址，返回后保留筛选。班级范围由后端授权。
- 课堂记录详情接入工作台与面包屑。只有已结束且已有草稿/正式总结的课堂可以确认总结；错误状态不显示空编辑表单。未保存修改在离开/刷新时提示。
- 教案新建、编辑与首次保存保留班级上下文；返回使用统一 BackButton。读取班级名称改为详情接口，不再仅从第一页班级列表查找。
- Preflight 从教案列表进入时携带来源，返回保持原备课路径。
- 课堂运行增加明确返回工作台入口；运行/暂停课堂离开时说明课堂继续，大屏继续，重新进入可恢复；不发送 complete/pause/cancel。
- 工作台退出登录前重新读取 active-run 并提示；退出按钮防重复执行。
- 总结页在正常或错误状态均提供课堂记录入口；返回班级定位到班级详情，避免“已结束后再次结束”的误导文案。
- 手机遥控增加常用暂停/继续、指定点名；取消结束确认不会抛出未处理错误。
- 正式大屏教学画面隐藏设备编号和连接详情、动作名称；加载及网络异常改为孩子可理解的提示；课堂舞台复用已有数字人展示组件。

## 兼容与后端
