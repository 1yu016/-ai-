# 管理员使用手册

## 登录与权限

管理员使用独立管理员登录入口。管理员可以维护平台资料和审计课堂，但不能无授权直接控制进行中的课堂。管理页面隐藏课堂遥控入口，服务端仍会对课堂教师、班级和设备进行校验。

## 数据看板

进入“数据看板”可查看：教师、班级、幼儿聚合数量；在线/离线设备；今日、进行中和异常课堂；待审核/停用资源；AI调用量、成功率、错误率、平均耗时；数据库和上传目录容量。

看板不展示幼儿姓名、作品或个人排名。统计按管理员所属园所隔离；全局管理员可查看全局聚合。

## 日常管理

1. **教师管理**：创建教师，修改姓名、角色和启停状态。停用账号后旧访问令牌也不能继续使用。
2. **班级与学生**：维护班级，把教师绑定到班级；检查跨园所关系时系统会拒绝保存。
3. **教室与设备**：维护设备、绑定班级和教室，查看心跳、最后在线时间、离线、故障或停用状态。
4. **资源审核**：查看待审核资源，批准、驳回或停用异常资源。停用前必须确认，停用资源不能进入正式课堂。
5. **数字人角色**：创建、审核、发布或停用角色及版本；缺失资源由课堂端安全降级。

## 审计日志

“审计日志”包含操作审计和 AI 调用两个只读页面。可按操作名、身份和结果筛选。普通教师不能访问，系统不提供日志修改或删除接口。

审计覆盖登录/退出、权限失败、账号班级设备修改、资源审核、课堂和手机命令、AI调用、奖励撤销、作品确认和导出。页面展示的 IP 和敏感元数据已脱敏。

## 异常处理

- 设备离线：检查大屏服务、局域网、心跳配置和设备停用状态。
- 异常课堂：先查看课堂时间线和操作审计，不直接替教师执行课堂控制。
- AI错误率升高：查看 AI 调用日志的 feature、provider、model、latency 和 errorCode；基础课堂功能应继续可用。
- 存储接近容量上限：先备份，再按资源引用关系处理文件，禁止直接删除数据库正在引用的文件。
