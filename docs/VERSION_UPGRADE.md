# 版本升级说明

1. 在维护窗口前完成数据库和上传目录备份及恢复校验。
2. 记录当前应用版本、Node.js 版本、依赖锁文件和环境变量名称。
3. 使用 `npm ci`，禁止在生产主机临时升级单个依赖。
4. 依次执行 lint、类型检查、单元测试、E2E 和构建。
5. 在独立副本上启动新版，让 TypeORM 同步仅用于当前开发形态；正式生产应改为显式迁移后再扩大部署。
6. 小范围验证登录、资源、备课、上课、暂停恢复和原有聊天。
7. 失败时停止写入，恢复应用版本、数据库和上传目录，禁止只回滚代码而保留不兼容数据。

本次阶段 10 增加前端测试依赖、独立 E2E 数据目录、可配置上传目录和教案 API 开发代理。管理员审核模块仍缺失，不能标记为正式冻结。
