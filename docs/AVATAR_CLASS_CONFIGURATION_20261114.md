## 已修复

1. 新建原先直接提交当前编辑表单，可能复制现有角色信息。现使用独立空白新建表单，教师明确填写后才调用创建草稿接口，取消不创建数据。
2. 班级分配入口原先在页面下方，缺少当前有效配置。现提前展示选择、分配和后端有效角色查询；保存后重新读取配置，不使用本地假成功状态。
3. 角色版本原先取第一个 ready 版本，可能错选。现在优先 currentVersionId 对应 ready 版本，兼容旧记录时才选最新 ready 版本；预览图使用同一版本，避免混用历史版本。
4. 当前课堂切换增加明确确认，原正式 Run 接口、版本及 requestId 校验保持不变。
5. 增加自配置顺序及真实限制说明，明确浏览器声音试听与云端音色验证有区别。

## 如何分配形象

1. 打开 http://localhost:5592/login，使用管理员身份登录。
2. 从左侧“数字人角色库”选择已发布角色。
3. 在上方“分配形象与课堂使用范围”选择目标班级，点击“设为班级默认角色”。
4. 查看“该班当前有效形象”的后端回查结果与版本。

班级绑定应用于后续创建课堂；教案绑定可覆盖班级默认。运行中课堂有独立固定角色/版本，切换当前课堂需走原有确认和正式操作接口。本轮没有替用户修改任何现有绑定。

## 如何自行配置

1. 管理员点击“新建角色草稿”，填写名称、分类、简介并创建。
2. 上传真实 GLB / GLTF / VRM 文件创建模型版本。普通 PNG / JPG 不会变成3D模型。
3. 为该模型版本上传所需附属资源。按当前后端完整性要求准备贴图、idle/speak 对应动作、口型配置、预览图、2D备用图；具体字段与格式以服务端校验反馈为准，不降低现有发布要求。
4. 在“角色资料”“声音与性格”编辑并保存。真实云端音色仍需已有语音服务授权；浏览器试听不能证明云端音色生效。
5. 点击模型版本“完整性检查并发布版本”，成功后提交角色审核并由管理员审核通过。
6. 发布完成后再分配班级或选择教案。
