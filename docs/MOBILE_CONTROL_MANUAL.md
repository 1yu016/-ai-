# 教师手机控制手册

## 加入课堂

1. 教师在大屏或课堂准备页获取一次性二维码。
2. 手机打开扫码入口，确认显示当前班级、课堂和大屏设备。
3. 加入成功后，手机显示连接状态、课堂步骤、资源、播放状态、考勤、最近点名和奖励。
4. 课堂结束、退出登录或凭证过期后，手机控制权限自动失效。

## 控制和回执

手机操作复用统一课堂命令入口。每条操作保留原 `requestId`，包含课堂版本和目标设备。状态依次可能为待发送、发送中、已接收、已执行、执行失败或已过期；收到服务端确认前不要把按钮显示为成功。

网络中断时页面显示离线。恢复后会重新鉴权、拉取完整课堂状态并继续接收事件；过期操作不会重发。版本冲突会清理过期客户端操作，以服务端状态为准。

## 局域网和缓存

手机、大屏和课堂服务器应连接同一园所局域网。缓存只保存课堂投影和资源 ID，不保存教师 Token、儿童敏感资料或原始音频。外部 AI 不可用时，基础课堂按钮仍可用。

## 故障处理

- 手机显示离线：检查 Wi-Fi，再等待自动重连；不要刷新后连续重复发送。
- 大屏离线：手机不会显示假成功，等待大屏恢复或回到教师端操作。
- 凭证过期：返回扫码入口重新加入，不复用旧二维码。
- 课堂已结束：重新进入课堂无控制权限，查看复盘页面。
