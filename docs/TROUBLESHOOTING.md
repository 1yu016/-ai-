# 常见故障排查

| 现象 | 检查 | 处理 |
| --- | --- | --- |
| 登录后立即退出 | 系统时间、JWT 密钥、过期时间 | 校准时间并确认所有实例使用同一密钥 |
| 页面显示网络连接失败 | 后端进程、反向代理、HTTPS | 检查健康接口与代理路径 |
| AI 超时或格式错误 | 模型端点、额度、超时日志 | 手动备课，稍后重试；不要保存非法输出 |
| 资源无法显示 | 文件是否存在、权限、MIME 类型 | 重新上传合法文件，不手改数据库路径 |
| 教案提示 409 | 是否多页面编辑 | 刷新后合并修改 |
| 请求过于频繁 | 429 日志和限流配置 | 等待窗口恢复，禁止无限重试 |
| 课堂刷新恢复失败 | `lesson_run` 是否存在、Token 是否有效 | 重新登录并从教案列表进入 |
| SQLite 锁定 | 并发写入、磁盘状态 | 停止异常进程，先备份再诊断 |

页面只应显示教师可理解的信息。堆栈、数据库路径和密钥只能进入受控服务日志。
