# 教师课堂工作台：独立评审原型

打开 `index.html` 即可使用，无需安装依赖或启动正式系统。顶栏可选择三套布局、十二种状态；右侧资源、教案、奖励、AI抽屉和底部模拟语音可交互。

本原型不调用API、不读写登录信息、不持久化业务数据，不加载真实模型或录制声音。标题、幼儿和资源为设计示例。正式业务是否可执行，以阶段三设计书中的接口审查、契约补齐和实机验收为准。

## 布局

- A：Stage First，底部横向工具。
- B：Presentation + Control，中央呈现、右侧高频控制；推荐默认。
- C：Teacher Cockpit，左主线、中央呈现、右工具。

## 验证

已使用本机无界面浏览器检查三种布局、十二种状态、1440×900 / 1366×768 / 1024×768，无水平溢出；推荐布局在三种视口均无整页垂直溢出，低频工具可在右栏内滚动。

已检查资源/教案Drawer打开不会改变模拟学生画面。录音、识别和AI执行状态也只改变教师反馈，不替换当前学生画面。关闭Drawer支持Esc，恢复触发按钮焦点；Tab在抽屉中循环。
