# 第三方服务配置

## 火山方舟模型

后端通过 OpenAI 兼容客户端连接火山方舟。配置 `ARK_API_KEY`、`ARK_ENDPOINT_ID` 和合理的 `AI_REQUEST_TIMEOUT_MS`。密钥只放在后端环境变量或密钥管理服务中，不得写入代码、文档、前端构建或日志。

模型返回内容必须继续经过 DTO 白名单校验；模型超时、非法 JSON 或安全校验失败时，教师应改用手动备课。AI 输出不能直接执行、播放或入库。

## 浏览器能力

录音、全屏和媒体播放受浏览器权限与自动播放策略约束。生产部署必须使用 HTTPS，并在园所批准的浏览器和投屏设备上单独验证。Playwright 测试只代表 Chromium 自动化环境，不代表真实投屏、麦克风或扬声器。
