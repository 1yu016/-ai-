## 7. 隐私字段规则

在没有 A 的正式字段和授权规则前，前端不能展示以下来源内容：

- 儿童真实姓名；
- 未授权头像、照片和声音；
- 原始问题文本；
- 儿童作品原图；
- 家庭情况；
- 心理、医疗、智力或品行判断；
- 能力排名或负面标签。

建议正式证据包默认只返回：

- 匿名统计；
- 主题和领域聚合；
- 服务端时间；
- 关联步骤；
- 已授权且当前教师有权查看的摘要。

最终字段必须以 A 的 DTO 和权限实现为准，B 不在前端自行脱敏或推断权限。
