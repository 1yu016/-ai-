# 任务12验收记录

## 验收覆盖

1. 六类奖励均能记录。
2. 相同 requestId 返回原奖励，不重复发放。
3. 奖励撤销保留奖励、撤销、徽章和成长审计。
4. 非当前课堂教师奖励返回 403。
5. 徽章、小红花、积分和成长值可以组合发放。
6. 班级成长流水和余额可追踪。
7. 荣誉候选使用多维度依据。
8. 展示冷却和学生轮换生效。
9. 无公开单一总分排名。
10. 无负面榜单。
11. 集体目标和集体荣誉可完成、确认和发布。
12. 进入课间前保存状态、步骤和课堂快照。
13. 数据库唯一索引阻止同一课堂多个有效课间。
14. 刷新通过 active 接口恢复倒计时。
15. 课间状态完全存储于数据库，不依赖服务进程内存。
16. 提前结束恢复原课堂步骤及运行/暂停状态。
17. 课堂完成或取消自动终止课间。
18. 终态课堂拒绝进入课间。
19. 历史功能纳入全量回归。

## 自动化用例

- 任务12功能验收：`test/classroom-run.e2e-spec.ts`
- 新迁移兼容验收：`test/avatar-migration.e2e-spec.ts`

最终命令和通过数量以本次执行结束时的真实输出为准。

## 残留风险

- 正式部署若使用非 SQLite 数据库，需要复验部分唯一索引和并发事务行为。
- 当前课间恢复返回服务端状态和倒计时，前端大屏仍需按接口结果恢复对应课间画面。
- 荣誉规则采用透明确定性规则，不使用儿童画像或AI诊断；后续调整规则应继续保持不公开排名和不输出负面标签。
