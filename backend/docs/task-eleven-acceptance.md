# 任务11验收记录

## 覆盖项

- 手动、批量、修改考勤及一人一课堂唯一约束。
- 学生历史考勤和变更日志。
- ASR 文本精确姓名/昵称匹配、相似姓名候选、未匹配待处理。
- 语音识别不写考勤，教师确认后才写入，确认凭证防重放。
- 分组增删改查、成员加入/移除、随机均匀分组和课堂成员快照。
- 全班、范围、分组和教师指定点名。
- 缺勤、请假排除和短期冷却。
- requestId 幂等。
- 候选集合、排除原因和算法版本审计。
- 12 轮点名中不重复最近两名，四名幼儿的点名次数差不超过 1。
- 其他教师越权写入返回 403。
- 迁移新增六张表，不改写已有课堂数据。

最终工程命令及结果以本次开发结束时实际执行输出为准，不在文档中预先声明通过。

## 边界与风险

- 语音考勤消费的是现有 ASR 输出文本，不包含持续监听或语音唤醒。
- 姓名相似匹配采用确定性的编辑距离，只提供候选，不会自动写入。
- 公平算法保证当前课堂内按点名次数和冷却窗口公平，不跨课堂建立儿童画像。
- 并发请求依赖数据库唯一约束保证 requestId 和当前考勤唯一；SQLite 写锁与正式数据库的并发行为仍需在部署数据库上复验。
