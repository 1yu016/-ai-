# 任务8验收报告

## 验收结论

1. 【通过】游客调用返回 401。
2. 【通过】非当前课堂教师返回 403，并再次校验班级权限。
3. 【通过】已结束课堂返回 409，不生成建议。
4. 【通过】教案步骤快照、班级年龄、课堂状态、已完成步骤、数据库事件、审核资源、点名/奖励摘要和数字人配置均由服务端读取；客户端剩余时间及事件文本不作为真实上下文。
5. 【通过】正常模型输出经过严格 DTO 白名单校验。
6. 【通过】非法 JSON 和字段缺失返回无动作的安全降级建议。
7. 【通过】模型超时、网络类错误和 429 不改变课堂运行状态。
8. 【通过】URL、JavaScript、脚本、SQL和系统命令触发安全降级，不保存为可执行动作。
9. 【通过】资源 ID 重新执行教师权限、课堂快照引用和审核状态检查，越权或未审核资源被过滤。
10. 【通过】步骤编号必须属于课堂步骤快照，非法步骤动作被移除。
11. 【通过】置信度低于 0.75 强制 `requiresConfirmation=true`。
12. 【通过】建议接口只保存记录，不调用课堂状态机；响应包含 `recordOnly=true`。
13. 【通过】`accepted`、`edited`、`rejected`、`ignored` 均可记录，编辑动作再次校验。
14. 【通过】`teacher_id + request_id` 唯一占位；相同完成请求幂等返回，处理中重复请求返回 409，模型不会重复调用。
15. 【通过】AI日志只保存脱敏摘要和统计，不包含密钥、教师完整请求或客户端儿童事件文本。
16. 【通过】自动测试使用 Mock 模型；未把 Mock 结果描述为真实模型验证。
17. 【通过】全部历史单元测试和 E2E 回归通过。

## 未验证风险

- 未调用真实模型，尚未验证第三方模型的实际延迟、限流策略、Token 统计准确性和输出质量。
- 当前数据库迁移与自动测试覆盖 SQLite；如生产改用其他数据库，需要在对应数据库上复验枚举、部分索引和并发唯一约束行为。
- AI建议只实现服务端接口，本任务不包含前端展示与交互验收。
