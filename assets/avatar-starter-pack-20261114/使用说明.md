# 原创卡通数字人形象文件包

本包仅为交付文件，未导入你的系统、未创建角色、未改变班级绑定。解压或查看文件不会执行导入。

## 三套角色

| 文件夹 | 角色名称 | 特点 |
|---|---|---|
| malt-bear | 麦芽熊老师 | 暖棕小熊、薄荷绿上衣、杏色围巾 |
| cloud-bunny | 云朵兔老师 | 奶白长耳兔、浅紫上衣、粉色围巾 |
| citrus-owl | 星橙猫头鹰 | 橙棕猫头鹰、蓝绿上衣、金色围巾 |

均为原创几何建模的简易卡通3D角色，不是VRM人形骨骼角色，不是图片改后缀。可用于本项目展示、修改及商业演示；不包含第三方人物模型或录制声音。形象不附带云端音色授权或大模型服务。

## 文件与上传位置

每套独立文件夹包含：

| 文件 | 系统中选择的用途 |
|---|---|
| model.glb | 创建模型版本，格式 GLB，引擎 avatar-engine-1 |
| texture.png | 上传版本资源 → 贴图 |
| idle.glb | 上传版本资源 → 动作 → idle（待机） |
| speak.glb | 上传版本资源 → 动作 → speak（说话，后端名称） |
| lip-sync.json | 上传版本资源 → 口型配置 |
| preview.png | 上传版本资源 → 预览图 |
| fallback.png | 上传版本资源 → 2D备用图 |
| manifest.json | 文件清单、动作名称及 SHA-256；不是系统支持的一键 ZIP 导入格式 |

主模型内嵌贴图及 Idle、Talk、Listening、Thinking、Question、Happy、Encourage、Wave、Goodbye 九种动画。动作文件另附待机与说话版本，以满足现有服务端资产完整性检查。口型是简单张嘴形变与 Talk 动画，不是精准音素口型同步。备用图就是相应3D模型实际渲染结果。

## 推荐导入方法：你手动运行本地工具

当前页面上传 GLB 可能不能自动填写后端所需的 model/gltf-binary MIME；另外动作菜单为 talk，后端实际要求 speak。为避免因这两个现有界面兼容问题导入失败，附带使用原有正式接口的本地导入工具，不修改或绕过服务端验证。

1. 完整解压文件包，保持三个角色文件夹和 import_avatar.py 在同一层。
2. 确认旧版后端 3592 已正常运行。此工具只连接本机 http://127.0.0.1:3592，不会启动、重启服务。
3. 使用本机 Python 3 运行 import_avatar.py；可在终端进入解压目录后输入 `python import_avatar.py`。
4. 选择一个角色，确认“导入”，在本机密码提示中输入系统管理员账号与密码。密码不会显示、保存或写入命令参数。
5. 工具逐个上传文件并请求服务端完整性检查。可选是否发布模型版本并提交角色审核；默认不自动审批，不分配班级。
6. 浏览器打开 5592 → 管理员登录 → 数字人角色库 → 选择该角色 → 预览并审核通过 → 选择班级自行分配。

工具不会自动运行；本次交付没有运行该工具，也没有向你正在使用的系统导入任何角色。不含账号、密码、API Key。不要把云端 API Key 当成系统管理员密码。

如不使用工具，可按上表逐个上传文件，但须先解决页面的 GLB MIME / speak 选项兼容问题。ZIP 本身只是方便分发的压缩包，不可直接上传为模型。

## 已做的检查与边界

- 三个 GLB 均经过 GLTFExporter 生成、GLTFLoader 重新加载、AnimationMixer 动作驱动及本地浏览器 WebGL 渲染。
- 21 个拟上传文件通过当前后端既有 validateAvatarFile 的离线检查；未调用真实导入接口、未修改数据库。
- 提供 manifest.json 的 SHA-256，可检查下载或解压后文件是否完整。
- 尚未在你实际运行的系统中验证角色发布、班级绑定、大屏、真实手机或物理音箱。
- 九种动画属于基础节点动画，不是人体骨骼重定向、复杂表情捕捉或精确唇形。
- 同名重复导入会停止，避免无意创建多份角色。导入中断时保留已有草稿，需在角色库检查后再操作。
