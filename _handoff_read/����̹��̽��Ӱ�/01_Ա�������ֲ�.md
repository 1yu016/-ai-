# 01 · 员工操作手册

本手册是"AI苦情歌MV抖音矩阵号"的**生产与验收标准**。完整规范以 `02_给豆包的交接材料\_员工生产SOP_最终版.md` 为准，本手册是浓缩版，方便你快速上手和验收。

## 一、这项目是干什么的

按编号批量生产"复刻包"，**每个编号 = 1份脚本 + 8张配图**：
- 脚本：20镜 / 65秒 / 逐镜文生视频提示词（含镜头、时间轴、参考图、口型对应歌词）
- 配图：8张参考图（AI做文生视频时每镜用哪张首帧，脚本里写死了）
- 全部放进 `05_脚本库\B0XX\` 一个文件夹，索引.txt 里登记进度

当前推广歌曲是《山里走出的娃》（深夜打工人思乡），下一待做编号是 **B015**。

## 二、开工前必须过的"核心逻辑5问"（答不上就换场景）

| 检查项 | 要回答的问题 |
|---|---|
| ① 为什么他在这唱歌？ | 这个场景里为什么会有唱歌这件事？（大排档麦架/婚礼话筒/候车厅小舞台…） |
| ② 他用什么唱？ | 手里必须是**真麦克风**，绝不能用手机 |
| ③ 为什么有人围观嘲讽？ | 周围人本来就在场，他上台才被围观，动机通顺 |
| ④ 他为什么被感动哭？ | 唱这首歌心里想的是谁、什么事？（送儿子上学/三年没回家…） |
| ⑤ 观众为什么被打脸？ | 闪回揭底：观众从笑他到哭他，中间被什么触动了？ |

场景只能从 SOP 白名单选：大排档/婚礼/社区舞台/小酒馆/候车厅/KTV/地下通道/年会寿宴酒席/工地天台深夜路边。
黑名单：火车站空地、路边走路、出租屋一个人、手机当麦克风。

## 三、爆款结构三铁律

**铁律1 · 黄金12秒 = 3轮递进式当众歧视**
第1轮(0-3s)反派A嗤笑 → 第2轮(3-6s)反派B补刀赶人 → 第3轮(6-9s)反派C拱火 → 主角全程沉默不顶嘴，9-11s默默接麦。
封面配文必须是冲突句式："XX也配唱XX？他一开口，刚才笑他的人全哭了"。

**铁律2 · 主场景唯一，闪回必须标注**
- 主场景从头到尾只有一个；人物图背景直接画成主场景
- 闪回镜号标题前标【闪回记忆】，提示词写"色调偏冷偏暗，与主场景区分"

**铁律3 · 观众反应是主线（占60%-80%）**
20镜制里观众反应 = 至少12镜；主角演唱特写 = 3镜（起腔/中段/高潮哭腔各一，参考图各不相同）；闪回2镜；收尾空镜1镜。

## 六、脚本写法要点

- 开头先放"📋 故事线总览"区块（一句话故事/人物/场景/观众情绪曲线6阶段/关键指标），再逐镜提示词
- 每个镜头必须含：时长、镜头类型（他拍/自拍）、参考首帧图文件名、运镜、画面内容、口型对应歌词句（演唱镜头）、结尾后缀"真实手机感。画面无字幕。中国人面孔，东亚特征，禁止西化。"
- 演唱镜头必须写清楚唱的哪句歌词（起腔/中段/高潮各对应一句）

## 八、常见坑（都是真实踩过的）

| 坑 | 表现 | 解法 |
|---|---|---|
| 嘲讽者表情画歪 | 钩子图生成出来是"放松吃串/惬意微笑" | 提示词必须写明"眉头紧锁/嘴角下撇/眼神斜睨/嫌弃"等负面神态词 |
| 手机当麦 | 主角拿手机唱歌 | 强调"手持麦克风，带防风罩"，闪回里才允许出现手机 |
| 比例不对 | 出横图或方图 | 竖屏9:16，生成参数 width:1080 / height:1920 |
| 人物不一致 | 高潮图/落泪图换了张脸 | 提示词写"与参考首帧完全同一人物：XX特征"，闪回里主角也保持一致 |
| 忘加西化后缀 | 出现西方面孔 | 每张图提示词结尾固定"中国人面孔，东亚特征，禁止西化" |
| 闪回不冷调 | 闪回跟主场景一个色 | 提示词写"色调偏冷偏蓝/偏暗，与主场景暖黄形成对比" |
| 参考图不足8张 | 分镜无图可用 | 缺一张都不算完工 |
