# 03 · 豆包协作指南

本指南说明两件事：**①怎么把交接材料交给豆包工作；②豆包交活后怎么验收、怎么打回。**
原则：你管标准（验收），豆包管执行（生产）。你不需要懂怎么写，但要会判好坏。

---

## 一、给豆包的材料清单（都在 `02_给豆包的交接材料` 里）

| 材料 | 作用 | 必须给吗 |
|---|---|---|
| `_员工生产SOP_最终版.md` | 核心规范（五问/铁律/20镜/8图/自检） | ✅ 每次必给 |
| `当前推广歌曲_歌词.txt` | 当前歌曲歌词，脚本要贴合它 | ✅ 每次必给 |
| `范本_B013（8图20镜）\` | 标准范本①（完整脚本+8图） | ✅ 首次必给，之后可引用 |
| `范本_B014（8图20镜）\` | 标准范本②（完整脚本+8图） | ✅ 首次必给 |
| `对标池总清单_B001-B062.txt` | 待做编号与母本信息 | ✅ 首次必给 |
| `脚本库索引.txt` | 进度登记，豆包做完更新它 | 随进度给 |

**交接材料会随项目更新**（新标准、新歌词、新范本）。每次换推广歌曲，就把新歌词放进 `02_给豆包的交接材料\当前推广歌曲_歌词.txt` 再发给豆包。

---

## 二、怎么把材料交给豆包（首次启动）

在豆包工作中新建对话，把上面材料**逐个上传**（文件/文件夹拖进去即可），然后发送下面这段指令（可整段复制）：

> 这是我们的爆款复刻工程 SOP 和范本，你按 SOP 里的规范接手 B015 及以后的脚本 + 配图生产。当前推广歌曲是《山里走出的娃》，歌词我发你了。你先读 SOP，再读 B013 整个文件夹作为范本，然后按编号往下做。

> 补充：我已把 B013、B014 回补到新标准（8图+20镜），这两集是唯二的标准范本，B011/B012 是老结构仅供参考。做完一集要更新索引。

**要点**：
- 一定要说"先读SOP，再读范本"，豆包会先吃透规范再动手
- 明确"按编号往下做"，让它自己从 B015 开始
- 每集做完主动让它停一下给你验收，不要一口气做一堆

## 三、日常指令话术

| 场景 | 对豆包说 |
|---|---|
| 做下一编号 | "继续做 B016"（或任意编号） |
| 某张图不对要重做 | "B015 的钩子图不对，表情写清楚点，要‘眉头紧锁/嘴角下撇/眼神斜睨/嫌弃’，打回重做" |
| 比例不对 | "这张不是竖屏9:16，打回重做，参数用 1080×1920" |
| 人物不一致 | "高潮特写和首帧不是同一个人，要同脸型同发型同衣服，打回重做" |
| 参考图不够 | "这一集才6张图，要8张（缺闪回1/落泪特写），补齐" |
| 脚本结构不对 | "脚本只有18镜/演唱特写不够3镜/观众反应不足12镜，按20镜标准重写" |
| 要回补旧集 | "把 B0XX 回补到新标准（8图+20镜）" |
| 验收不合格全盘重来 | "按自检清单逐条过，哪条不过就改哪条，改完重新交付" |

**打回重做三原则**：
1. 一次说清"哪张图/哪个镜、哪里不对、希望改成什么样"（参考上面的坑表）
2. 表情类问题必须给负面神态词（眉头紧锁/撇嘴/嫌弃/斜睨），只说"表情不对"它猜不准
3. 人物一致问题必须说"同脸型同发型同衣服"，不能只说"保持一致"

## 四、验收清单（每集交付后逐项核对）

**图片（8张）**
- [ ] 张数=8：主角首帧 / 主角高潮哭腔特写 / 钩子反派 / 反应群像 / 反应落泪特写 / 场景空镜 / 闪回1 / 闪回2
- [ ] 每张竖屏9:16
- [ ] 主角拿真麦克风（闪回除外）
- [ ] 同一个人物前后一致（尤其高潮图 vs 首帧）
- [ ] 闪回图冷色调，与主场景区分
- [ ] 无第三方Logo文字，无西化面孔

**脚本（20镜65s）**
- [ ] 总镜头20镜，总时长65s
- [ ] 观众反应≥12镜（60%+），按6阶段递进（嘲讽→嗤笑收住→不可置信→震惊→落泪→安静收尾）
- [ ] 主角演唱特写=3镜（起腔/中段/高潮哭腔），参考图各不相同
- [ ] 闪回2镜且标【闪回记忆】+冷色调说明
- [ ] 前12秒3轮嘲讽（0-3/3-6/6-9，主角沉默9-11接麦）
- [ ] 每个镜头标了参考首帧图文件名
- [ ] 演唱镜头写了对应歌词句
- [ ] 结尾"中国人面孔，东亚特征，禁止西化"

**收尾**
- [ ] 索引.txt 已更新该编号状态

## 五、常见问题（FAQ）

**Q：豆包说图片工具不能用 / 生成失败？**
A：让它报具体错误，检查是不是网络/配额问题，稍后重试或换图生图（image_edit）重做。生成失败的图不算数，必须补齐8张。

**Q：豆包一次做太多，错得也太多？**
A：改成"一次只做一集"，做完一集先验收再让它做下一集。宁慢勿错。

**Q：豆包生成的图和范本风格不像？**
A：让它"参考范本 B013/B014 的图"重做，或把范本图作为参考图传给它（图生图）。

**Q：换推广歌曲了怎么办？**
A：更新 `02_给豆包的交接材料\当前推广歌曲_歌词.txt`，重发指令："当前推广歌曲换成XXX，歌词发你了，后续按新歌情绪做"。

**Q：怎么知道做到哪一号了？**
A：看 `脚本库索引.txt` 或直接问豆包"现在做到哪了，还有哪些待做"。

## 六、你（员工）和豆包的分工

| 环节 | 谁干 |
|---|---|
| 定标准（SOP、歌词、验收口径） | 项目方/本交接包 |
| 生产脚本+8图 | 豆包工作 |
| 逐张验收、打回、定稿 | 你 |
| 并入脚本库、更新索引 | 你（豆包也可代做，你复核） |
| 最终成片（文生视频、剪辑） | 剪辑组（豆包给出逐镜提示词和首帧图） |

一句话：**标准在包里，执行靠豆包，质量你把关。**
